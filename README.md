# mybadboss.app

The public website for **My Bad Boss AI** — a smart alarm for people with
real shifts, by LuxWaveLabs LLC.

Static site served by GitHub Pages at [mybadboss.app](https://mybadboss.app).

| Page | Path |
|---|---|
| Landing | `/` |
| Privacy Policy | `/privacy/` |
| Terms of Service | `/terms/` |

No build step — plain HTML/CSS. Edit a file, push to `main`, Pages redeploys.

> App source code lives in a separate private repository. Nothing here is
> connected to the app runtime.
